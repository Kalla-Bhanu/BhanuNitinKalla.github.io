## Disable GitHub Pages

To fully stop hosting from GitHub:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages**.
4. Under **Build and deployment**, set **Source** to **None** or disable Pages.
5. Save the change.

If GitHub does not show a disable option, remove the Pages deployment source branch/folder and save.
