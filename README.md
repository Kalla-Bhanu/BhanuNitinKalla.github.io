### Detection Mindset

Good defensive engineering should make the analyst's next decision easier:

1. Identify the risky behavior.
2. Validate the telemetry.
3. Add identity, asset, and cloud context.
4. Tune for precision.
5. Document the response path.
6. Feed recurring patterns back into stronger detections.
