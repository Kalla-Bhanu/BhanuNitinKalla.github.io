### Detection Mindset

Good detection work should answer three questions clearly:

1. What behavior is unusual or risky?
2. What evidence helps an analyst decide quickly?
3. What can be automated or documented so the next investigation is faster?

I like projects that are practical, explainable, and easy to review: clean datasets, clear detection logic, readable dashboards, and investigation notes that tell the story.
